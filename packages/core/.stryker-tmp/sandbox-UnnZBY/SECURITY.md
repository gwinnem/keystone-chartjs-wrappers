# Security Policy

This package is part of the **keystone-chartjs-wrappers** monorepo.

The full security policy — including supported versions, how to report a
vulnerability, and expected response times — is maintained in the root
[SECURITY.md](https://github.com/gwinnem/keystone-chartjs-wrappers/blob/main/SECURITY.md).

**Please do not open a public GitHub issue to report a security
vulnerability.** Use GitHub's private
[Security Advisories](https://github.com/gwinnem/keystone-chartjs-wrappers/security/advisories/new)
or email **geirr@winnem.tech** instead.
