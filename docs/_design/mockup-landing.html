SPECIFICATION

Everything the wrapper does

01
One generic component

A single <Chart> per framework — set `type`, not a different import per chart.

02
8 built-in chart types

Bar, Line, Bubble, Doughnut, Pie, Polar Area, Radar, Scatter.

03
5 ecosystem extensions

Financial (candlestick/OHLC), boxplot/violin, matrix, sankey, treemap.

04
Official interaction plugins

Zoom/pan, annotations, and data labels wired in and typed.

05
Lazy type registration

Only the chart controllers you actually use are registered — tree-shaking preserved.

06
TypeScript-first

Every prop, config, and chart kind typed and exported from one entry point.

07
Responsive by default

Canvas resize handling built into the shared core, not left to each framework.

08
Framework-agnostic core

Chart lifecycle and registry logic usable standalone, no framework required.

09
Mixed & combo charts

Bar+line combination charts via Chart.js's own per-dataset `type`.

10
Reactive updates

Data/options changes diffed into the live chart, not a full destroy/recreate.

11
Battle-tested

Vitest unit/component tests, Playwright e2e, and mutation testing across all three.

12
Theme-aware

Light/dark token re-application on theme change, handled by the core.
