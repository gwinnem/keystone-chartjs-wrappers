## Built-in chart types

All 8 built-in kinds are registered eagerly at module load (via
`Chart.register(...registerables)`), so every example below is live and
interactive.

- **[Bar chart](/vue/examples/bar-chart/)** — the simplest possible setup, with an in-place data update.
- **[Horizontal bar chart](/vue/examples/horizontal-bar-chart/)** — the same `bar` kind with `indexAxis: 'y'`, not a separate chart type.
- **[Line chart](/vue/examples/line-chart/)** — a week of signups.
- **[Bubble chart](/vue/examples/bubble-chart/)** — `{x, y, r}` data points, radius independent of the axes.
- **[Scatter chart](/vue/examples/scatter-chart/)** — `{x, y}` data points, no `labels` array.
- **[Doughnut chart](/vue/examples/doughnut-chart/)** — proportional data with a hollow center.
- **[Pie chart](/vue/examples/pie-chart/)** — proportional data as full wedges.
- **[Polar area chart](/vue/examples/polar-area-chart/)** — proportional data on a radial scale.
- **[Radar chart](/vue/examples/radar-chart/)** — multi-axis comparison across several datasets.

## Ecosystem extension chart types

All 7 of these kinds are lazily registered — the backing package is
dynamically imported the first time a chart of that kind renders, so a
project that never uses one never pays for it in its bundle. Real source
shown for each; not yet live-embedded on this docs site (see each
page's own note for why).

- **[Candlestick chart](/vue/examples/candlestick-chart/)** — `chartjs-chart-financial`, `{x, o, h, l, c}` per point.
- **[OHLC chart](/vue/examples/ohlc-chart/)** — the same package and data shape as candlestick, drawn as tick marks instead of a filled body.
- **[Box plot chart](/vue/examples/boxplot-chart/)** — `@sgratzl/chartjs-chart-boxplot`, a raw `number[]` per box with statistics computed automatically.
- **[Violin chart](/vue/examples/violin-chart/)** — the same package and data shape as box plot, drawn as a kernel-density distribution.
- **[Matrix chart](/vue/examples/matrix-chart/)** — `chartjs-chart-matrix`, `{x, y, v}` per cell with scriptable cell size.
- **[Sankey chart](/vue/examples/sankey/)** — `chartjs-chart-sankey`, `{from, to, flow}` per link.
- **[Treemap chart](/vue/examples/treemap-chart/)** — `chartjs-chart-treemap`, a flat `number[]` for the simplest case.

## Mixed charts

Every built-in kind is registered eagerly, so this example is live and
interactive too — no extension package involved.

- **[Mixed chart](/vue/examples/mixed-chart/)** — a bar chart with one dataset overridden to `type: 'line'`, drawn overlaid on the same axes.

## Axes

Every example here uses only built-in scale types, so it's live and
interactive too.

- **[Multiple axes](/vue/examples/multi-axis/)** — two datasets with different units, each mapped to its own `y` scale via `yAxisID`.

## Interaction

- **[Chart events](/vue/examples/chart-events/)** — Chart.js's own native `options.onClick`, reacting to which bar was clicked. No extra prop or Vue event needed.

## Official plugins

All 10 of these are fully implemented and shipped in this library —
see the [Official plugins overview](/vue/examples/official-plugins/) for
what that means versus custom/inline plugins.

- **[Colors plugin](/vue/examples/colors-plugin/)** — Chart.js's own built-in `Colors` plugin, registered and enabled by default. Live and interactive — no extension package involved.
- **[Zoom plugin](/vue/examples/zoom-plugin/)** — a local port of `chartjs-plugin-zoom` with a real wheel/pinch/pan config. Live and interactive — being local code, not a dynamic import, it never hit the docs-site hydration gap the still-dependency-based plugins below do.
- **[Annotation plugin](/vue/examples/annotation-plugin/)** — `chartjs-plugin-annotation`, drawing lines, boxes, points, labels, polygons, and ellipses on the chart area. Real source shown; not yet live-embedded on this docs site (see that page's own note).
- **[Data labels plugin](/vue/examples/data-labels-plugin/)** — `chartjs-plugin-datalabels`, rendering a label directly on each data element. Real source shown; not yet live-embedded on this docs site (see that page's own note).
- **[Gradient plugin](/vue/examples/gradient-plugin/)** — a local port of `chartjs-plugin-gradient` with a real per-dataset gradient config. Live and interactive, for the same reason as zoom above.
- **[Timestack scale](/vue/examples/timestack-scale/)** — `chartjs-scale-timestack`, an alternative time axis formatting time in two stacked, human-friendly rows. Real source shown; not yet live-embedded on this docs site (see that page's own note) — its own real `luxon` dependency can't be resolved the same way local code can.
- **[Hierarchical scale](/vue/examples/hierarchical-scale/)** — a local port of `chartjs-plugin-hierarchical`, a collapsible tree-like categorical axis. Live and interactive, including the real click-to-expand/collapse/zoom-in/zoom-out interaction.
- **[Image label plugin](/vue/examples/image-label-plugin/)** — a local port of `chartjs-plugin-image-label`, adding image labels to doughnut chart slices via Chart.js's own inline `plugins` array. Live and interactive, for the same reason as zoom above.
- **[Autocolors plugin](/vue/examples/autocolors-plugin/)** — a local port of `chartjs-plugin-autocolors`, automatically assigning a distinct color per dataset. Live and interactive, for the same reason as zoom above.
- **[Deferred plugin](/vue/examples/deferred-plugin/)** — a local port of `chartjs-plugin-deferred`, deferring a chart's own real initial update (and its initial-render animations) until the canvas scrolls into the viewport. Live and interactive, for the same reason as zoom above.
- **[Trendline plugin](/vue/examples/trendline-plugin/)** — a local port of `chartjs-plugin-trendline`, fitting a real linear or exponential trend line to each dataset. Live and interactive, for the same reason as zoom above.
