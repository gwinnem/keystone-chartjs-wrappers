The `annotation` prop wires in a local port of `chartjs-plugin-annotation`
(real source dissected directly from the installed package's own real,
unminified ESM build, not just its README) — by far the largest, most
architecturally distinct port in this project: seven real annotation
types (`box`, `doughnutLabel`, `ellipse`, `label`, `line`, `point`,
`polygon`), each its own genuine Chart.js `Element` subclass, registered
via `Chart.register(annotationPlugin)`, which in turn registers all
seven element classes via its own `afterRegister()` hook.

Being local code rather than a dynamic import also means this example
is genuinely live on this docs site, like `zoom`/`gradient`/
`hierarchical`/`imageLabel`/`autocolors`/`deferred`/`trendline`/
`dataLabels` — unlike `timestack`, the one remaining real npm
dependency in this project, which still renders source-only here.

:::tip[No plain-boolean form, unlike zoom/dataLabels]
`annotation` has no boolean opt-in form — `AnnotationPluginOptions.annotations`
is required, since there's no sensible empty default (the same reasoning
as `imageLabel`'s own `imagesList`). Its real config merges into
`options.plugins.annotation.annotations`. See
[Plugins](/vue/api/plugins/) for the full prop reference.
:::

:::note[Real, distinct capabilities found only by reading the source]
- **Real scale auto-range-adjustment** — an annotation value outside a
  scale's own current min/max automatically extends that scale to fit
  it (`adjustScaleRange`), unlike every other plugin in this project.
- **Real interaction-mode hit-testing** — click/hover routes entirely
  through Chart.js's own `beforeEvent` hook and a real, dedicated
  interaction-mode resolver (`options.interaction`: `nearest`/`point`/
  `x`/`y`), not raw DOM events.
- **A real bug found and fixed during the port** — the original names
  its teardown hook `destroy`, which Chart.js's real `Plugin` interface
  doesn't recognize at all; renamed to `afterDestroy`, the correct real
  hook name, alongside switching the original's own plain `Map`
  per-chart bookkeeping to a `WeakMap`.

See [Plugins](/vue/api/plugins/) for the full prop reference.
:::
