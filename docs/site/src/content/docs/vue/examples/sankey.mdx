`sankey` is one of the 5 ecosystem extensions, not a Chart.js built-in —
the real `chartjs-chart-sankey` package is dynamically imported and
registered the first time any `<Chart type="sankey">` mounts, not
eagerly bundled for every consumer regardless of whether they use it.
