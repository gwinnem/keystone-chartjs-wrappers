`treemap` is one of the 7 ecosystem extensions, not a Chart.js built-in —
the real `chartjs-chart-treemap` package is dynamically imported and
registered the first time any `<Chart type="treemap">` mounts, not
eagerly bundled for every consumer regardless of whether they use it.

:::tip[Data shape is a flat `number[]`, for the simplest case]
No `tree`/`key`/`groups` needed at all for a single-level treemap like
this one — `chartjs-chart-treemap` also supports pre-grouped hierarchical
data, but a flat array of numbers alongside a matching `labels` array is
its own simplest supported shape. See
[Chart kinds](/vue/api/chart-kinds/) for the full list of extension
kinds and which package backs each one.
:::
