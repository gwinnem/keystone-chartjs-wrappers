Chart.js supports multiple X and Y axes on a single chart — useful whenever
two datasets share a chart but represent different units. This example
plots temperature and visitor count on the same six months, each on its own
`y` scale: `options.scales` defines `y` (left) and `y1` (right), and each
dataset maps to one via its own `yAxisID`.
