The `imageLabel` prop draws image labels on doughnut/pie chart arcs.
Unlike every other plugin on this site, it isn't a dependency on a
third-party package at all — its logic is ported directly into
`keystone-chartjs-core` (`src/imageLabelPlugin.ts`), fixing two real
bugs found in the original package along the way: it now draws labels
for every dataset (not just the first), and positions each image using
Chart.js's own already-computed arc geometry instead of recomputing
slice angles from raw values.

Being local code rather than a dynamic import also means this example
is genuinely live on this docs site — unlike the
[timestack](/vue/examples/timestack-scale) example, which still hits a
docs-site build-pipeline gap around dynamic imports (its own real
`luxon` dependency currently can't be resolved the same way).

It's supplied per-chart-instance, via Chart.js's own real inline
`plugins` array (the same mechanism the [`plugins` prop](/vue/components/props)
already exposes for custom/community plugins) — this prop's own
resolved plugin object is appended to whatever `plugins` array is
already in effect, additively rather than replacing it.

:::tip[No plain-boolean form, unlike zoom/dataLabels]
`imagesList` is required — there's no sensible empty default, the same
reasoning as `annotation`'s own `annotations` field. Each entry needs an
`imageUrl`/`imageWidth`/`imageHeight`; `verticalAlign`/`horizontalAlign`/
`offset` control label placement within each slice. See
[Plugins](/vue/api/plugins) for the full prop reference.
:::
