`candlestick` is one of the 7 ecosystem extensions, not a Chart.js
built-in — the real `chartjs-chart-financial` package is dynamically
imported and registered the first time any `<Chart type="candlestick">`
mounts, not eagerly bundled for every consumer regardless of whether
they use it.

:::caution[Not yet live-embedded on this docs site]
This example isn't hydrated on this page yet — this docs site resolves

extension kinds like `candlestick` doesn't currently resolve correctly

:::

:::tip[Data shape is `{x, o, h, l, c}`]
This is `chartjs-chart-financial`'s own real data-point shape (open/
high/low/close), not something `keystone-chartjs-vue` reinterprets — the
same shape `ohlc` uses too, since both kinds are backed by this same
package and differ only in how each point is drawn. See
[Chart kinds](/vue/api/chart-kinds/) for the full list of extension
kinds and which package backs each one.
:::
