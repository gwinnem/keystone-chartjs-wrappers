A horizontal bar chart isn't a separate chart kind — it's Chart.js's own
regular `bar` controller with one option set: `indexAxis: 'y'`. Category
labels run down the y axis instead of across the x axis, and values run
left-to-right instead of bottom-to-top.

<ExampleTryIt code={HorizontalBarChartSource} filename="horizontal-bar-chart.vue">
  <HorizontalBarChart client:visible />
</ExampleTryIt>

:::tip[Still just `type="bar"`]
`<Chart type="bar">` is unchanged — `indexAxis` lives entirely inside
`options`, which reaches Chart.js untouched. No extra prop, no separate
component.
:::
