The `hierarchical` prop opts into the real `chartjs-plugin-hierarchical`
package, registered on first use — like `gradient`/`timestack`, it's
boolean only: it registers a real, distinct `hierarchical` **scale**
(not a Chart.js "plugin" object) via its own confirmed named export
(`HierarchicalScale`), with no plugin-level config of its own to merge
here either. Use it by setting
`options.scales.<id>.type = 'hierarchical'`, which already reaches
Chart.js untouched via the existing `options` prop.

:::tip[A real, distinct tree-node data shape]
```js
data.labels = [
  { label: '2024', children: ['Q1', 'Q2', 'Q3', 'Q4'] },
];
dataset.data = [
  { value: 100, children: [20, 25, 22, 33] },
];
```
`label`/`children` on the labels side, `value`/`children` on the data
side — a real, distinct shape from the flat arrays every other kind or
plugin in this library accepts, confirmed directly from the real
package's own type declarations
(`ILabelNode`/`IValueNode`). See
[Plugins](/vue/api/plugins) for the full prop reference.
:::
