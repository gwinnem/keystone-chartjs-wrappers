The `zoom` prop draws on a local port of `chartjs-plugin-zoom`. Like
[gradient](/vue/examples/gradient-plugin) and
[image label](/vue/examples/image-label-plugin), it isn't a dependency
on a third-party package at all — its logic is ported directly into
`keystone-chartjs-core` (`src/zoomPlugin.ts`).

:::tip[Pinch-zoom and touch/pen pan, reimplemented without Hammer.js]
The original `chartjs-plugin-zoom` drives pinch-zoom and drag-to-pan
through Hammer.js, which is itself unmaintained (confirmed via a real,
open upstream issue). Rather than dropping those two features along
with that dependency, this port reimplements both directly on the
standards-based **Pointer Events API**
(`pointerdown`/`pointermove`/`pointerup`/`pointercancel`), which unifies
mouse/touch/pen input with no external dependency at all:

- **`zoom.pinch.enabled`** — two-finger pinch-zoom.
- **`pan.enabled`** — single-finger (or pen) drag-to-pan, honoring
  `pan.threshold`/`onPanStart`/`onPanRejected`/`onPanComplete`.

**Mouse input is deliberately excluded from this pointer-event path**:
mouse users get wheel-zoom and drag-to-zoom-rectangle only, with
`chart.pan()` still callable *programmatically* (see the pan buttons
below) but no interactive mouse-drag-to-pan gesture — the original
package never had a mouse-only pan gesture either, so this isn't a new
limitation. The full programmatic API (`chart.zoom()`, `chart.zoomRect()`,
`chart.zoomScale()`, `chart.resetZoom()`, `chart.pan()`,
`chart.getZoomLevel()`, and more) is unaffected by any of this.
:::

Being local code rather than a dynamic import also means this example is
genuinely live on this docs site — unlike the
[timestack](/vue/examples/timestack-scale) example, which still hits a
docs-site build-pipeline gap around dynamic imports (its own real
`luxon` dependency currently can't be resolved the same way).

Try it on a touch or pen device: single-finger drag pans, two-finger
pinch zooms.

:::tip[`zoom` has no required config, unlike `annotation`]
`annotation` has no plain-boolean form — `AnnotationPluginOptions.annotations`
is required, since there's no sensible empty default. `zoom` and
`dataLabels` both accept either `true` or a config object; see
[Plugins](/vue/api/plugins/) for the full prop reference.
:::
