The `zoom` prop opts into the real `chartjs-plugin-zoom` package,
registered on first use. Passing `true` applies it with no extra
config — this example passes a real config object instead, since the
plugin itself needs explicit `wheel`/`pinch`/`pan` settings to actually
respond to anything.

:::tip[`zoom` has no required config, unlike `annotation`]
`annotation` has no plain-boolean form — `AnnotationPluginOptions.annotations`
is required, since there's no sensible empty default. `zoom` and
`dataLabels` both accept either `true` or a config object; see
[Plugins](/vue/api/plugins/) for the full prop reference.
:::
