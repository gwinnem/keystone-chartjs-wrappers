The `dataLabels` prop wires in the real `chartjs-plugin-datalabels`
package, dynamically imported and registered the first time any
`<Chart dataLabels>` mounts — one of the two remaining
still-dependency-based plugins in this library (alongside
`annotation`), unlike `zoom`/`gradient`/`hierarchical`/`imageLabel`,
which are all local ports.

:::tip[Accepts either `true` or a config object, like `zoom`]
`dataLabels` merges its real config into `options.plugins.datalabels` —
pass `true` for the plugin's own defaults (shown here), or a config
object (e.g. `{ color: 'white', font: { weight: 'bold' } }`) to
customize label placement, formatting, and styling. See
[Plugins](/vue/api/plugins/) for the full prop reference.
:::
