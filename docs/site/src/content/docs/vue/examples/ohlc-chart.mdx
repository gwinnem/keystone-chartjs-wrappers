`ohlc` is one of the 7 ecosystem extensions, not a Chart.js built-in —
the real `chartjs-chart-financial` package (the same one `candlestick`
uses) is dynamically imported and registered the first time any
`<Chart type="ohlc">` mounts, not eagerly bundled for every consumer
regardless of whether they use it.

:::caution[Not yet live-embedded on this docs site]
This example isn't hydrated on this page yet — this docs site resolves
`keystone-chartjs-core` from this monorepo's own workspace source, not a
published package, and the dynamic import that lazily registers
extension kinds like `ohlc` doesn't currently resolve correctly across

:::

:::tip[Data shape is `{x, o, h, l, c}`, identical to candlestick]
`ohlc` and `candlestick` share the exact same data-point shape (open/
high/low/close) and the same backing package — they differ only in how
each point is drawn (tick marks either side of a high-low line, versus
a filled body). See [Chart kinds](/vue/api/chart-kinds/) for the full
list of extension kinds and which package backs each one.
:::
