The `timestack` prop opts into the real `chartjs-scale-timestack`
package, registered on first use — like `gradient`, it's boolean only:
there's no `Chart.register(...)`-able export at all (the package
registers its own scale as a side effect of being imported) and no
plugin-level config of its own either. Use it by setting
`options.scales.<id>.type = 'timestack'`, which already reaches Chart.js
untouched via the existing `options` prop.

:::tip[Real, hard dependency on Luxon]
`chartjs-scale-timestack` requires `luxon` for locale-aware time
formatting — a real, sizeable added dependency if you opt into this
scale, not merely optional. Data points must be `{x, y}` with
millisecond timestamps; X-values as labels aren't supported, and custom
tick `callback`s are ignored — see the
[package's own README](https://github.com/jkmnt/chartjs-scale-timestack)
for its full list of documented constraints. See
[Plugins](/vue/api/plugins) for the full prop reference.
:::
