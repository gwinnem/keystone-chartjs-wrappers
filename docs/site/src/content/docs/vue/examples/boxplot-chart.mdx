`boxplot` is one of the 7 ecosystem extensions, not a Chart.js built-in —
the real `@sgratzl/chartjs-chart-boxplot` package is dynamically
imported and registered the first time any `<Chart type="boxplot">`
mounts, not eagerly bundled for every consumer regardless of whether
they use it.

:::tip[Data shape is a raw `number[]` per box]
`@sgratzl/chartjs-chart-boxplot` computes the five-number summary
(min/q1/median/q3/max) and outliers automatically from each series' own
raw values — no pre-computed statistics needed. See
[Chart kinds](/vue/api/chart-kinds/) for the full list of extension
kinds and which package backs each one.
:::
