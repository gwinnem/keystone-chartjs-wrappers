`violin` is one of the 7 ecosystem extensions, not a Chart.js built-in —
the real `@sgratzl/chartjs-chart-boxplot` package (the same one
`boxplot` uses) is dynamically imported and registered the first time
any `<Chart type="violin">` mounts, not eagerly bundled for every
consumer regardless of whether they use it.

:::caution[Not yet live-embedded on this docs site]
This example isn't hydrated on this page yet — this docs site resolves

published package, and the dynamic import that lazily registers

itself. Expected to resolve once this package is built/published for

:::

:::tip[Data shape is a raw `number[]` per series, identical to boxplot]
`violin` and `boxplot` share the exact same raw-values-per-series shape
and the same backing package — they differ only in how each series is
drawn (a full kernel-density distribution shape, rather than a
five-number-summary box). See [Chart kinds](/vue/api/chart-kinds/) for
the full list of extension kinds and which package backs each one.
:::
